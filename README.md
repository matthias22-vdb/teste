# Orbit ✳

Une petite animation web autonome : sphère lumineuse, orbites et fond nocturne.

## Lancer

Téléchargez le dépôt (Code → Download ZIP), décompressez-le et ouvrez **index.html** dans votre navigateur. Conservez `style.css` et `script.js` dans le même dossier. Aucun serveur, installation ou accès Internet nécessaire.

## Interagir

- Déplacez la souris : la sphère suit légèrement votre mouvement.
- Cliquez sur le fond : une onde lumineuse apparaît.
- **Changer la couleur** : faites défiler cinq palettes.
- **Mettre en pause / Reprendre** : contrôlez le mouvement.

L’interface s’adapte au mobile, les boutons fonctionnent au clavier et la préférence système de réduction des animations est respectée.

## Fichiers

- `index.html` : structure de la page.
- `style.css` : apparence, animations et adaptation mobile.
- `script.js` : interactions, sans dépendance.
